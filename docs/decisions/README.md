# Decision records

One short file per decision that is hard to reverse, or that keeps coming back. Each file has a status, a date, a source
(Timon's words or a commit), the context, the decision and its consequences. A decision is never edited afterwards. A
new record replaces it, and the old one gets `Status: superseded by NNNN`.
